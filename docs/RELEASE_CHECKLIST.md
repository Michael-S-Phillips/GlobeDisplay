## Build, archive & upload (you — commands below)

Automatic signing needs your account, so pass `-allowProvisioningUpdates`:

```bash
cd /Volumes/Fangorn/SIC_Management/GlobeDisplay
xcodegen generate

# Archive (signed)
xcodebuild -project GlobeDisplay.xcodeproj -scheme GlobeDisplay \
  -destination 'generic/platform=iOS' \
  -archivePath build/GlobeDisplay.xcarchive \
  -allowProvisioningUpdates archive

# Export for App Store and upload (create ExportOptions.plist with method = app-store-connect)
xcodebuild -exportArchive \
  -archivePath build/GlobeDisplay.xcarchive \
  -exportPath build/export \
  -exportOptionsPlist ExportOptions.plist \
  -allowProvisioningUpdates
```

Or, simplest: open `GlobeDisplay.xcodeproj` in Xcode → **Product → Archive** →
**Distribute App → App Store Connect → Upload**.

`ExportOptions.plist` minimal example:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key><string>app-store-connect</string>
    <key>teamID</key><string>K7M2M2864C</string>
    <key>destination</key><string>upload</string>
</dict>
</plist>
```
