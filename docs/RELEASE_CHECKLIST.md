## Day-to-day install on the iPad (operational mode)

The lpl-sic Apple ID is a member of team `33AV9322Z6` with **Developer / basic access** —
enough to install development builds on a device with ~1-year provisioning profiles, but
not enough to upload to App Store Connect or create distribution profiles.

To install / re-install GlobeDisplay on the iPad:

1. Plug the iPad into the Mac via USB-C/Lightning. Unlock and Trust This Computer if prompted.
2. On the iPad (one-time): **Settings → Privacy & Security → Developer Mode → On** (reboots).
3. On the Mac:
   ```bash
   cd /Volumes/Fangorn/SIC_Management/GlobeDisplay
   xcodegen generate
   open GlobeDisplay.xcodeproj
   ```
4. In Xcode, pick the iPad in the destination dropdown and press **Cmd+R**.
5. First time only, on the iPad: **Settings → General → VPN & Device Management** →
   Developer App → trust the `lpl-sic@arizona.edu` entry.
6. Plug in the USB-C → HDMI adapter → MagicPlanet for the external display.

Re-runs from Xcode refresh the provisioning. With the paid team, you only need to do this
once a year (vs. weekly on the previous free-account setup).

## Build, archive & upload (you — commands below)

Automatic signing needs your account, so pass `-allowProvisioningUpdates`:

```bash
cd /Volumes/Fangorn/SIC_Management/GlobeDisplay
xcodegen generate

# Archive (signed)
xcodebuild -project GlobeDisplay.xcodeproj -scheme GlobeDisplay \
  -destination 'generic/platform=iOS' \
  -archivePath build/GlobeDisplay.xcarchive \
  -allowProvisioningUpdates archive

# Export for App Store and upload (create ExportOptions.plist with method = app-store-connect)
xcodebuild -exportArchive \
  -archivePath build/GlobeDisplay.xcarchive \
  -exportPath build/export \
  -exportOptionsPlist ExportOptions.plist \
  -allowProvisioningUpdates
```

Or, simplest: open `GlobeDisplay.xcodeproj` in Xcode → **Product → Archive** →
**Distribute App → App Store Connect → Upload**.

`ExportOptions.plist` minimal example:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key><string>app-store-connect</string>
    <key>teamID</key><string>33AV9322Z6</string>
    <key>destination</key><string>upload</string>
</dict>
</plist>
```
